STUBBED satellite / GLOF image set
==================================

Free real-time glacier/GLOF satellite access is not available for this
hackathon demo. `scenes.json` is a static catalogue. `StubGlacierCNN` in
`backend/app/l1_ingestion/glacier.py` implements the CNN *interface* and
returns plausible scores from these scene ids.

Do not describe this path as live satellite inference in the demo.
